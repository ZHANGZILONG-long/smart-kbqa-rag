# 学习笔记

这里是我在独立完成 SmartKBQA 期间积累的学习材料，记录的是**从计算机基础到能交付一个系统**的过程。

这些笔记不是教程搬运，是"卡住 → 想通 → 回头写下来"的产物。每份文档都尽量做到三件事：
**先问它解决什么问题 → 再往下追问机制 → 最后给出能在本项目里验证的落点。**

> 背景：我不是科班出身里基础扎实的那一类。毕业后面临就业困难，一边做临时工作维持生活，
> 一边把后端基础补了起来，最后独立完成了 [项目主体](../..)。这些笔记就是那段时间的痕迹。

## 阅读建议

这几份文档有明确的分工，**不要通读**：

- 想快速了解项目 → 只看 **一页速查卡**
- 想读懂代码 → 按 **学习路线** 的顺序
- 想补基础 → **计算机基础入门**（零基础）或 **计算机基础学习**（求原理）
- 卡在某个问题上 → **问题排查框架** + **没见过的问题怎么下手**

**每份文档末尾都有自测题。答不出来就说明还没读懂，回去重读对应章节。**
通读一遍的收获，远不如把一份文档的自测题全部答对。
